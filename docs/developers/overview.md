# Developer Documentation

Open Pattern Format is an XML based specification which can describe a yarn based pattern and project. Pattern files use XML macros to provide dynamic elements which can generate custom project files based on user preferences.

Open Pattern Format consists of two closely related specifications. One for describing a pattern and another for describing a project. A pattern file is used to generate a project file which can then be read by any compatible reader software. A pattern requires 'packaging' before it can be distributed which is a means of making a pattern self-contained with all images and other associated data.
